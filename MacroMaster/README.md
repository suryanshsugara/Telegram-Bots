# MacroMaster Bot 💪🤖

A smart Telegram bot that calculates personalized macros, gives daily workouts, and generates diet plans — all from your chat.

📍 **Project Path:** `Telegram-Bots/MacroMaster`
🔗 [View on GitHub](https://github.com/suryanshsugara/Telegram-Bots/tree/main/MacroMaster)

## 🚀 Features
- Custom macro calculation
- Workout plans by day
- Diet planner (premium)
- UPI/PayPal-based access model
- Spoonacular API integration

## 🛡️ Secure your credentials
Create a `.env` file using `.env.example` and fill in your API keys.

## 📦 Install
```bash
pip install -r requirements.txt
python main.py
```

## 🧰 Upload Instructions (for beginners)

### 1. Clone your main repo
